# Digital Twin — Foundations

This project combines the implementation from Lab 3, Lab 4, and the Lab 5 Extra exercise.

## Learning progression

**Digital Twin foundations → tools → first Agent Loop → Pushover → dynamic tools → Python modules → visible Agent Loop**

The notebook keeps the implementation and concepts from the original lectures while removing course/promotional instructions and adding concise comments in my own learning voice.

## Main technologies/concepts

- Python
- OpenAI API
- Gradio
- Pushover
- Function/tool calling
- Conversation history
- Context engineering
- Agent Loops
- Dynamic tool execution with `globals()`
- Python modules

The work is intentionally built without an agent framework so I can understand the underlying mechanics before moving to higher-level frameworks.
